# AI Powered Code Reviewer

## 1. Introduction

This project is an AI-powered code review application built with Python and CustomTkinter. The program allows users to paste source code into a graphical interface and receive an automatic analysis generated by Google Gemini AI.  

The application evaluates code in terms of:
- Code style  
- Efficiency  
- Possible bugs  
- Improvement suggestions  

---

## 2. Requirements and Specifications

To run the application, users need Python installed along with the following libraries:

- customtkinter  
- pyperclip  
- google-generativeai  

In addition, an internet connection and a valid Google Gemini API key are required.

### Features:
- Modern GUI built with CustomTkinter  
- Code input area for users  
- Language selection (Python, JavaScript, C++, Java, C#)  
- AI-generated code analysis reports  
- Clipboard support for copying results  
- Error handling for missing API keys and server issues  

When the user clicks the analyze button, the code is sent to the Gemini API with a prompt requesting a professional review in simple English. The result is then displayed in the output section.

---

## 3. Testing

The application was tested using multiple code samples and programming languages to ensure stability and correctness.

### Test cases included:
- Valid source code input (Python, JavaScript, C++)  
- Empty input submission test  
- Running without an API key file  
- Simulated server overload (503 error handling)  
- Copy and clear button functionality  

### Retry System:
The application includes a retry mechanism for server errors. If a 503 error occurs, the app waits 5 seconds and retries up to 5 times before showing a final error message.

---

## 4. Results

The application successfully analyzed source code and produced readable AI-generated reports. During testing, the interface remained responsive and user-friendly.

### AI feedback included:
- Style improvements  
- Efficiency optimization  
- Bug detection  
- Cleaner code suggestions  

Error handling worked correctly, displaying user-friendly messages instead of crashing the application.

## 5. Conclusion

This project demonstrates how artificial intelligence can be integrated into desktop applications to support software development.

The AI Powered Code Reviewer combines:
- Python programming  
- GUI development (CustomTkinter)  
- AI integration (Google Gemini API)

Users can paste code, select a programming language, and receive automatic AI feedback. The system provides a practical example of how modern AI tools can enhance programming workflows.
